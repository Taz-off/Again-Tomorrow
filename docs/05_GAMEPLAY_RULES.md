# Gameplay Rules (canon)

1. `livedMinutes` commence à 0, augmente toujours, ne descend jamais.
2. Pas de `timeCurrency`. « Dépenser » = faire avancer la vie.
3. Optimisation = réduire une durée pour le même résultat.
4. `timeSavedMinutes` = statistique, pas une monnaie.
5. `timeRemaining` n'existe pas dans le slice 1 (révélation tardive).
6. Souvenirs non monétisables en productivité.
7. Valeur manquante à impact design → `DECISION REQUIRED`, ne pas inventer.
