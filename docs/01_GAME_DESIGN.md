# Game Design (canon, résumé slice 1)

Boucle : dépenser du temps (faire avancer `livedMinutes`) → obtenir une
ressource → mieux utiliser le temps suivant. Les optimisations réduisent
des durées, jamais de portefeuille de minutes.

Slice actuel (30 min) : passer 1 minute, Observer (2 min → +1 connaissance),
Réfléchir (3 min → +1 idée), Regarder la pluie (17 min → souvenir, 0 gain),
Travailler (30 min → +10 argent, optimisable à 25 min).

Interdits slice 1 : temps restant, mortalité, immortalité, dette temporelle
avancée, TEMPUS complet, employés, IA avancée, cosmique, fin.
Voir `roadmap/CURRENT_SLICE.md`.
