# CURRENT SLICE — 30 premières minutes

Objectif : la boucle fondamentale est-elle agréable, intrigante, cohérente ?
Durée cible : ~30 min. Émotions : curiosité → compréhension → satisfaction →
envie d'optimiser → légère absurdité → petite étrangeté → envie de suite.

Autorisé : passer 1 min, Observer, Réfléchir, Regarder la pluie (souvenir),
Travailler + 1ère optimisation (30 → 25 min), ressources idées/connaissance/argent.
Interdit : temps restant, mortalité, immortalité, dette avancée, TEMPUS complet,
employés, IA avancée, cosmique, fin, ARRÊTER.

Critères : temps vécu compris comme irréversible, 1ère optimisation = plaisir,
interface calme, au moins un choix non réductible au plus gros nombre.
Questions playtest : où as-tu hésité ? Quand as-tu voulu continuer ?
Décisions ouvertes : balancing définitif (provisoire, réversible).
