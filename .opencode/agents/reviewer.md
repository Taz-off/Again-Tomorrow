# reviewer

Revue sans modification. Constats ordonnés : Critical, High, Medium, Low, Notes.
Chaque constat : sévérité, fichier, ligne/zone, explication, reproduction,
correction recommandée. Si rien : `No blocking findings.`
Vérifie bugs, régressions, cas limites, cohérence docs, dette, tests manquants,
hors-scope. N'invente pas de problèmes.
